# The lid is not a vault

PawDrop assumes one trusted administrator, a private application network, and a trusted host. The host and its backups can read all files. Anyone with a download URL can read the associated file, without a login. There is no encryption at rest, user management, one-time link, or automatic expiry for downloads.

## Guardrails

- Unique random session token per successful login; only the newest session is active. Server-side expiry uses a monotonic clock. Logout and process restart invalidate it. The cookie is HttpOnly and SameSite=Strict, with Secure enabled by default. Authenticated mutations require a session-specific CSRF token. In-flight requests are not canceled on logout.
- Password comparisons are constant-time for equal-length byte strings. Choose a high-entropy password; length alone is not a guarantee. The gateway limits login requests per immediate source address (shared behind an edge). Distributed guessing, denial of service and shared-limit exhaustion are outside this small app's guarantees.
- Random download keys are generated by default. Custom keys must be independently random. Existing short keys are supported only for backward compatibility. Rotate a leaked key by deleting it and uploading under a new key.
- HTML escapes user-facing values. Links use a configured origin or relative paths, not the incoming Host header. Downloads are attachments with nosniff. Responses set no-store, no-referrer and frame restrictions. The UI uses small inline CSS/JS and a matching CSP; it is not a strict nonce-based CSP.
- Nginx and Uvicorn access logs are disabled. Nginx request error logs are discarded to avoid revealing URL credentials; this reduces troubleshooting visibility. Review upstream access/error logs, browser history, chat messages, monitoring, backups and other systems where URLs might still appear. No-store cannot prevent recipients from saving data.
- Only the `.txt` filename extension is enforced; content is not scanned or guaranteed to be UTF-8. The app does not execute uploads. An attachment can still contain harmful or sensitive content. There is no aggregate storage quota or automatic garbage collection; monitor disk and memory usage.

Use HTTPS for any remote deployment, set `COOKIE_SECURE=true`, restrict backend connectivity, and keep dependencies and container images updated. Run only one worker. Direct Uvicorn access is unsupported for public traffic: the gateway supplies request-body and login rate limits. Report issues without including actual bearer links, passwords or internal network details.
